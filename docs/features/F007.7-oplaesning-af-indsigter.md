# F007.7 — «Skal jeg læse artiklen højt?» — oplæsning af indsigter

## Motivation

Ejer-bestilling (Christian 4/9-2026, med screenshots): når Aidan refererer en «indsigt» (en news post — posts-samlingen, IKKE almindelige sider), skal tilbuddet «Skal jeg læse artiklen højt for dig?» intelligent dukke op, og oplæsningen skal virke.

## Reuse

- **TTS: @broberg/ai-sdk `ai.tts`** (F020.4) — ElevenLabs, kureret dansk stemme-roster (soren/jesper/mads/noam/camilla), `{ text, voice, lang }` → `{ audio, mimeType, usage }`. INGEN rå provider-integration. `voiceFallback` sættes BEVIDST IKKE: Aidans stemme er en identitet — går stemmen af pension hos ElevenLabs skal det alarmere, ikke tale videre med en fremmed stemme (sdk'ens egen F037-vejledning).
- **Artikeltekst: `tilTekst()` fra trail-clip.ts** — samme rensning som Trail-kæden bruger, allerede bevist.
- **Nøgle: ELEVENLABS_API_KEY** findes i ai-sdk/.env → kopieres til sitets .env + Fly-secrets (aldrig printet).

## Løsning

**Server** (`src/aidan-laes.ts`):
- `GET /api/aidan/indsigter` → liste af posts-stier (fra søgeindekset, KUN posts-samlingen) — klientens facitliste for hvornår tilbuddet vises.
- `POST /api/aidan/laes { sti }` → validerer stien mod samme liste (server-autoritativ; alt andet 404), henter egen side, `tilTekst()`, kalder `ai.tts({ text, voice: 'mads', lang })`, svarer audio-bytes.
- **Cache pr. indholds-hash** (sha256 af teksten) på disk — TTS er dyr (pr. tegn hos ElevenLabs); samme artikelversion koster ét kald. Tekst-loft ~12k tegn.
- Ship-dark uden nøgle (503). Rate-limit 3/min pr. IP (dyrere end chat).

**Klient** (`enhance.ts`):
- Efter et færdigt svar: hent (én gang, lazy) indsigts-stierne; matcher et link i svaret → tilføj tilbuds-knap under svaret (første match, ét tilbud pr. svar).
- Klik → henter-state → afspil via Audio; klik igen = pause/fortsæt. Fejl → fejltekst.
- Testids: aidan-laes-tilbud.

**Tekster i CMS-globals da+en**: aidanLaesTilbud, aidanLaesHenter, aidanLaesPause, aidanLaesVidere, aidanLaesFejl.

## Non-goals

- Ingen oplæsning af almindelige sider/løsningssider (kun posts — eksplicit i bestillingen)
- Ingen afspiller-UI ud over knappen (ingen scrub-bar i v1)
- Ingen forudgenerering af lyd ved publicering (cache fylder on-demand)

## Verifikation

Unit-tests på sti-validering + cache-nøgle; fuld suite + tsc; Lens-E2E på levende site (tilbud vises kun ved indsigts-link, afspilning starter, currentTime > 0); cache bevist med to kald (andet svarer uden TTS-kald — målt på log). Deploy via grøn port (F302).
