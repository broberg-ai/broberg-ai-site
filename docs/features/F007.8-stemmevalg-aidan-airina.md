# F007.8 — Info-knap + stemmevalg Aidan/Airina

## Motivation

Ejer-bestilling (Christian 4/9-2026, med screenshot af «Aidan er en AI»-linjen): en info-knap ved disclaimeren der popper info op om Aidan, og hvor man kan skifte til Airina — gemt i cookie — så Christels stemme bruges ved højtlæsning. Christian har hørt Christel (Azure da-DK) i cardmem og vil have en YNGRE MANDLIG stemme som Aidans egen.

## Reuse

- **Stemmerne er ai-sdk's kuraterede Azure-roster** (AZURE_DANISH_VOICE_LIST): Aidan = `jeppe` (da-DK-JeppeNeural, mandlig native), Airina = `christel` (da-DK-ChristelNeural). Engelske artikler: `andrew`/`ava` (multilinguale). Ingen rå Azure-integration — alt via `ai.tts(…, override:{provider:'azure'})`.
- **AZURE_SPEECH_KEY** genbruges fra cardmems miljø (samme Azure Speech-ressource) → sitets .env + Fly-secrets.

## Løsning

1. **Info-knap** i foden ved disclaimer-teksten (`aidan-info-knap`) → popover (`aidan-info-popover`) med kort info om Aidan (CMS-felt `aidanInfo`) og «Hvem skal læse højt?» med to valg: Aidan / Airina (`aidan-persona-aidan`/`-airina`).
2. **Cookie `aidan_persona`** (max-age 1 år, path=/) — Christians eksplicitte valg af cookie frem for localStorage. Læses ved læs-højt-klik og sendes som `persona` i POST /api/aidan/laes.
3. **Serveren** (F007.7-modulet) slår stemme op pr. (persona, locale) og cacher pr. (indhold, stemme).
4. **Kun stemmen skifter i v1.** Navn/figur-skift til en Airina-figur afventer at figuren findes i supers Assets — noteret som muligt F007.8.2.

## Tekster (CMS-globals da+en)

`aidanInfo`, `aidanVaelgStemme`, `aidanStemmeAidan`, `aidanStemmeAirina` + F007.7's `aidanLaes*`-felter.

## Verifikation

Suite + tsc; Lens-E2E: info-knap → popover synlig → vælg Airina → cookie sat (document.cookie indeholder aidan_persona=airina) → genindlæs → valget står stadig. Stemmeforskellen høres ikke af Lens — den bevises via serverens log (stemme-navnet logges) + cache-nøgle-testen. Deploy via grøn port (F302).
