# F007.13 — Marker-protokol: alle 20 resultat-tilstande

## Motivation
Ejer-ordre (Christian 5/9-2026): «Byg ALLE» — de 20 nummererede resultat-tilstande fra mockup 01a0712a («den bedste chat-oplevelse EVER, for det sælger billetter»). 1–2 (handlings-svar, oplæsning) findes; dette bygger 3–20.

## Arkitektur — én mekanisme, ikke 18
Modellen udsender små MARKØRER på egne linjer; klientens lukkede, escape-først renderer (src/client/aidan-md.ts) veksler dem til rige blokke. Samme kontrakt som [knap:] (Eir-mønstret): et token med kendt form, aldrig «style noget HTML».

| Nr | Tilstand | Mekanisme |
|---|---|---|
| 3 | Case-kort | `[case:/sti\|Titel\|linje]` → kort med monogram + CTA |
| 4 | Tabel | markdown-tabellinjer (`\| a \| b \|`) → `<table>` |
| 5 | Mini-graf | `[graf:2,5,3,8]` → inline SVG-sparkline |
| 6 | Kilder | `[kilder:/sti\|Titel;…]` → foldbar kildeliste |
| 7 | Trin-guide | eksisterende `<ol>` + nummer-cirkel-styling |
| 8 | Pris-kort | primer-mønster (fed ramme + knap) — ingen ny markør |
| 9 | Book-møde | `[tider]` → 3 chips (næste hverdage) → kontakt m. foreslået tid |
| 10 | Vis på siden | `[vis:tekstanker]` → luk panel på mobil, scroll+highlight |
| 11 | Tænke-skridt | SSE `status`-events fra serveren før/under stream |
| 12 | Afklarings-chips | `[valg:A\|B\|C]` → chips der sender valget som besked |
| 13 | Persona-håndover | scene i anvendPersona (fade + vinke-tekst) |
| 14 | Send-svar-mail | knap pr. svar → POST /api/aidan/send-svar (samtykke, bcc, lead-log, mail-core-brev) |
| 15 | Video-svar | `[video:/uploads/x.mp4]` — KUN /uploads-stier |
| 16 | Live-status | `[status]` → GET /api/aidan/status + målt roundtrip |
| 17 | Opsummering | chip efter ≥3 brugerture → skjult opsummer-prompt + mail-tilbud |
| 18 | Venlig fejl | fetch-fejl/429 → boble + «Prøv igen» (gensender sidste) |
| 19 | Sprog-skifte | `[sprog:en\|da]` → efterfølgende kald bærer det locale |
| 20 | Konfetti | `[fejr]` → CSS-konfetti + kvittering |

## Sikkerhed
- Escape-FØRST bevaret: markører genkendes på escaped tekst; felter er tekst, aldrig HTML. Unit-test pr. markør med ondsindet input.
- [video:] kun /uploads/*.mp4; [vis:] matcher kun synlig tekst; tools-seglet urørt.
- send-svar: samtykke===true håndhævet server-side (400 ellers), EMAIL_RE, bcc cb@webhouse.dk, lead-JSONL — samme kontrakt som send-lyd (F007.9).

## Reuse
@broberg/mail + mail-core-skallen (eksisterende), ai-sdk uændret. Ingen nye pakker.
