# F007.12 — Mobil: Aidan fuldskærm + scroll-lås + CTA-luk

## Motivation
Ejer-rapport (Christian 5/9-2026, F180.6 — defekt i kørende session): «Når jeg launcher Aidan initialt så kører scrolle omme bagved, det virker forkert. Kan du ikke også på mobil bare få chat til at fylde fuld skærm og når der klikkes på en knap så luk chat dialog.»

## Root cause
1. aabn() kaldte felt.focus() uden preventScroll — browseren scrollede siden bagved for at vise input-feltet ved åbning.
2. Ingen scroll-lås: touch-scroll i chatten kædede videre til siden bagved (scroll chaining).
3. Mobil-panelet var et hjørne-kort (right/bottom 8px), ikke fuldskærm.
4. En [knap:]-CTA i et svar navigerede, men panelet blev stående ovenpå og dækkede den side man bad om.

## Løsning (src/client/enhance.ts + src/styles/brand.css)
- felt.focus({ preventScroll: true }) i aabn().
- html.aidan-aaben sættes/fjernes i aabn/lukPanel; CSS låser overflow KUN under 560px — desktop-siden skal kunne rulle bag hjørne-panelet.
- @media (max-width: 560px): .aidan-panel inset 0, 100vw/100dvh, radius 0, ingen border; fuldskærms-knappen (data-testid aidan-fuld) skjules; .aidan-panel.fuld neutraliseres (centrerings-transformen ville ellers KRYMPE panelet på mobil).
- overscroll-behavior: contain på .aidan-msgs.
- Klik-delegation på .aidan-msgs: a.aidan-cta → lukPanel().

## Reuse
Ingen ny capability — ren frontend-adfærd på eksisterende Aidan-widget; intet @broberg/*-pakkebehov.

## Verifikation
Gates (tsc + 85 bun-tests) grønne før deploy; Lens mobil-viewport (390×844) efter deploy: panelet dækker viewporten, og siden bagved står stille ved åbning.
