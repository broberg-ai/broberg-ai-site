# F007.6 — Foldbare forslags-chips i Aidan-chatten

## Motivation

Ejer-bestilling (Christian 4/9-2026, med screenshot): forslags-chippene fylder en stor del af panelet og bliver stående efter man har valgt ét — «når man vælger en af dem så vis en animation hvor de foldes ned og en fold ud knap kommer frem.»

## Løsning

1. **Fold ned ved valg.** Chip-klik eller egen afsendt besked tilføjer `.foldet` på `.aidan-chips` — CSS-transition på max-height + opacity (respekterer reduced motion via kort transition), og en lille «Forslag»-pill med chevron (`data-testid="aidan-chips-fold"`) vises i stedet.
2. **Pillen toggler.** Klik folder ud/ind; chevron roterer med tilstanden.
3. **Starttilstand følger samtalen.** Frisk besøg/Ny samtale: udfoldet, ingen pill. Genindlæst samtale med beskeder: foldet (man er i gang — forslag er støj).

## Scope

- `src/client/enhance.ts`: fold-tilstand + pill-klik i `aidan()`
- `src/components/AidanWidget.tsx`: pill-markup, tekst fra globals `aidanForslag` (da+en — tekst bor i CMS)
- `src/styles/brand.css`: `.aidan-chips`-transition, `.foldet`, pill-styles m. hover/active/focus + `[hidden]`-regel

## Non-goals

- Ingen ændring af hvilke chips der vises (stadig globals `aidanChips`, loft 4)
- Ingen persistens af fold-tilstand på tværs af sider

## Verifikation

Lens-E2E på levende site (chip-klik → foldet + pill; pill → udfoldet); fuld suite + tsc; deploy via grøn port (F302).

## Genbrug

Mønstret deles med sanne (Eir) via intercom; how implementerer det allerede — del af det fælles chat-lag foreslået components.
