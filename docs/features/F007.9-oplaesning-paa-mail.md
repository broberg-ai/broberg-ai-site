# F007.9 — «Få oplæsningen tilsendt på mail» — lead-indsamling via lydfilen

## Motivation

Christians idé 4/9-2026, GO samme aften: «…er det muligt at vi kan streame talen ned i en fil på serveren samtidigt så vi kan tilbyde at sende den til brugeren på mail? På den måde kan vi lokke til at få samlet deres mail op.» Svaret var ja med rabat: F007.7 cacher allerede HELE lydfilen på serveren pr. (indhold, stemme) før afspilning — mailen er ren levering + lead.

## Reuse

- **@broberg/mail 0.10.1** (exact-pin) via `createMailerFromEnv()` — aldrig rå Resend. Ship-dark uden nøgle; pakkens fail-safe (live=false → kun allowlist) beskytter indtil MAIL_LIVE=true.
- **hentLyd()** udtrukket af F007.7-modulet — én kilde til sti-validering, rensning, cache og TTS, delt af /laes og /send-lyd.
- **Resend-domænet broberg.ai** oprettet i husets konto (EU, eu-west-1); DKIM/SPF-poster lagt via buddy (DNS-reglen). Dedikeret API-nøgle «broberg-ai-site», kun sending-adgang, kun dette domæne.

## Løsning

1. **UI**: når afspilningen starter, vises formularen under knappen — mail-felt, custom samtykke-boks (tegnet, ikke native styling), Send. Succes erstatter formularen med «Sendt»-tekst; fejl vises i status-linjen. Alle tekster i CMS-globals da+en.
2. **Server** `POST /api/aidan/send-lyd { sti, persona, email, samtykke }`: samtykke === true HÅNDHÆVES SERVER-SIDE (fluebenet er kun UI), email-validering, samme sti-facitliste som /laes, rate-limit 3/min.
3. **Mailen**: emne «Din oplæsning: <titel>», lydfilen vedhæftet (mp3, typisk 2–4 MB), link til artiklen, afsender Aidan <aidan@broberg.ai>. **bcc cb@webhouse.dk** — det er både kopireglen og selve lead-opsamlingen.
4. **Leads** appendes som JSONL på den varige disk (`/data/aidan-leads.jsonl`): email, sti, titel, persona, samtykke, tidspunkt, leveret.

## Non-goals

- Ingen nyhedsbrevs-tilmelding/dobbelt-opt-in i v1 (samtykketeksten dækker filen + relevant nyt; skal listen bruges til udsendelser, kræver det sit eget flow)
- Ingen download-link i stedet for vedhæftning (cachen er ephemeral — et link dør ved deploy)

## Verifikation

Suite + tsc; live: send til cb@webhouse.dk (allowlist-sikkert selv før MAIL_LIVE), assert 200 + mail modtaget med vedhæftning; lead-linjen læst tilbage fra /data; samtykke=false → 400 bevist med rå kald. Deploy via grøn port (F302).
